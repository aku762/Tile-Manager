A JSON-driven static homepage generator. Edit tiles in a drag-and-drop admin panel, export `tiles.json`, and deploy a pre-rendered site to Cloudflare Pages in one build step.

## How it works

- **Local preview** — open `site/index.html` via Live Server. `app.js` fetches `tiles.json` and `site.json` at runtime and hydrates the page dynamically. No build step needed.
- **Production build** — `npm run build` reads `site/index.html`, substitutes `{{SITE_*}}` tokens from `site.json`, pre-renders all tiles from `tiles.json`, and writes everything to `dist/`. The `app.js` script tag is stripped from the output.
- **Deploy** — point Cloudflare Pages at the repo with build command `npm run build` and output directory `dist`.

## Project structure

```
core/               ← build engine — safe to pull upstream updates
  build.js          ← reads site/, writes dist/
  app.js            ← local preview hydration (tiles + site.json tokens)
  admin.js          ← admin panel logic
  admin.css         ← admin panel styles
  admin.html        ← admin panel UI

site/               ← your customizations — never touched by core updates
  index.html        ← template + local preview entry point
  site.json         ← site metadata (title, logo, footer, etc.)
  tiles.json        ← sections and tile data
  style.css         ← public site styles
  images/           ← logo, og image, tile images

dist/               ← gitignored build output (generated by npm run build)
```

## Getting started

1. **Clone the repo**
2. Edit `site/site.json` with your site details
3. Open `site/index.html` with [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) to preview locally
4. Use `admin.html` (also via Live Server) to manage tiles visually — export `tiles.json` when done
5. Push to GitHub and connect to Cloudflare Pages

## site.json tokens

| Token | Field |
|---|---|
| `{{SITE_TITLE}}` | `title` |
| `{{SITE_DESCRIPTION}}` | `description` |
| `{{SITE_TAGLINE}}` | `tagline` |
| `{{SITE_URL}}` | `url` |
| `{{SITE_LOGO}}` | `logo` |
| `{{SITE_OG}}` | `og` |
| `{{SITE_FOOTER}}` | `footer` (supports HTML) |

## Tile images

Drop images into `site/images/tiles/`. The build also looks for WebP variants at:
- `site/images/tiles/webp600/<name>.webp` (600w)
- `site/images/tiles/webp900/<name>.webp` (900w)

Missing images are hidden gracefully via an `onerror` handler — tiles display without a broken image.

## Admin panel

Open `dist/admin.html` (after a build) or `core/admin.html` directly via Live Server. The admin panel saves state to `localStorage` under the key `tile_manager_admin`. Use **Export JSON** to write `tiles.json` back to `site/`.

## Cloudflare Pages settings

| Setting | Value |
|---|---|
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js version | 18+ |

Web Analytics: enable in **Pages → Settings → Web Analytics** rather than hardcoding a beacon token in the template.
